InstanSeg détecte les noyaux, les cellules, ou les deux. Commencez toujours sur une petite annotation: une bonne segmentation sur une lame entière ne se règle pas à l'aveugle.

## Installer l'extension

1. Installez [QuPath 0.7]({{ site.baseurl }}{% post_url 2025-01-01-Installation-de-QuPath %}).
2. Dans QuPath, ouvrez **Extensions > Manage extensions**.
3. Installez **Deep Java Library** puis **InstanSeg** avec le bouton `+` vert.
4. Acceptez le dossier utilisateur proposé par QuPath, puis redémarrez QuPath.

Deep Java Library est nécessaire à InstanSeg. Si vous utilisez un GPU NVIDIA, installez d'abord le pilote NVIDIA puis suivez le [guide CUDA]({{ site.baseurl }}{% post_url 2026-02-19-perf-cuda-installation %}). Sur Mac Apple Silicon, choisissez `mps` si cette option est proposée; sinon commencez en `cpu`.

## Lancer une première détection

1. Ouvrez une lame dont la calibration est connue.
2. Dessinez une annotation de test, avec environ 100 à 500 cellules représentatives.
3. Dans **Extensions > InstanSeg**, ouvrez la commande de détection et téléchargez le modèle proposé si nécessaire.
4. Choisissez l'annotation sélectionnée comme zone d'analyse.
5. Commencez avec `cpu`, une taille de tuile de `512` px et une marge de `32` px.
6. Lancez la détection, puis zoomez sur les bords de la ROI.

Choisissez `Nuclei` si seul le noyau vous intéresse. Choisissez `Cells` ou `Nuclei + Cells` seulement si les limites cellulaires sont visibles dans l'image. Ne modifiez qu'un paramètre à la fois.

## Contrôle qualité obligatoire

Validez le résultat sur trois zones: tissu dense, tissu peu dense et bord de lame. Vérifiez qu'une cellule n'est ni découpée en plusieurs objets, ni fusionnée avec sa voisine. Supprimez les détections test avant de relancer un réglage, sinon les objets s'accumulent.

## Script reproductible

Après avoir validé les réglages dans l'interface, conservez-les dans un script Groovy. Dans **Automate > Show script editor**, adaptez le chemin du modèle puis lancez le script sur les annotations sélectionnées.

```groovy
import qupath.ext.instanseg.core.InstanSeg

def annotations = getSelectedObjects().findAll { it.isAnnotation() }
if (annotations.isEmpty())
    throw new IllegalArgumentException('Sélectionnez au moins une annotation.')

InstanSeg.builder()
    .modelPath('/chemin/vers/model.onnx')
    .inputChannels('Red', 'Green', 'Blue')
    .outputChannels('Nuclei', 'Cells')
    .pixelSize(0.5)
    .tileDims(512)
    .interTilePadding(32)
    .device('cpu')
    .makeMeasurements()
    .build()
    .detectObjects(annotations)
```

Remplacez seulement `cpu` par `gpu` ou `mps` après avoir obtenu le meme résultat sur la ROI test.
