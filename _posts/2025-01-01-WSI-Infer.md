# Tutoriel WSI Infer pour QuPath : installation et vérification de compatibilité

Ce tutoriel décrit une procédure propre pour installer **WSI Infer** dans **QuPath** puis vérifier si l'extension est réellement utilisable avec **QuPath 0.7**.

Au **3 mars 2026** :
- la version QuPath 0.7 que j'ai pu vérifier officiellement est **`v0.7.0-rc1`**
- le README officiel de **WSI Infer** indique des tests sur **QuPath `v0.5.1`** et **`v0.6.0-rc6`**
- je n'ai pas trouvé de source primaire confirmant la compatibilité de **WSI Infer** avec **QuPath 0.7**

Conclusion pratique : installez d'abord QuPath 0.7, puis testez WSI Infer sur une copie de projet avant de l'utiliser sur un vrai lot.

---

## 1. Introduction

**QuPath** est un logiciel libre dédié à l'analyse d'images en pathologie numérique. L'extension **WSI Infer** étend ses fonctionnalités en permettant l'inférence (i.e. l'exécution de modèles de deep learning) directement sur vos images WSI, facilitant ainsi le repérage et la quantification de régions d'intérêt.

---

## 2. Prérequis

Avant de commencer, assurez-vous de disposer de :

- **QuPath** installé sur votre système :
  - [Télécharger QuPath 0.7](https://github.com/qupath/qupath/releases/tag/v0.7.0-rc1)
- Une version récente de Java (souvent fournie avec QuPath).
- Une connexion Internet pour télécharger l'extension.
- (Optionnel) Des modèles d'apprentissage profond pré-entraînés, selon les besoins de votre analyse.

---

## 3. Installation de l'Extension WSI Infer

### 3.1. Téléchargement de l'Extension

1. **Accéder à la source de l'extension :**  
   Rendez-vous sur le dépôt officiel de l'extension : [qupath-extension-wsinfer](https://github.com/qupath/qupath-extension-wsinfer).

2. **Télécharger le fichier .jar :**  
   Téléchargez la dernière version du fichier `.jar` depuis la page Releases du dépôt.

### 3.2. Ajout de l'Extension à QuPath

1. **Localiser le dossier des extensions :**  
   Le dossier des extensions QuPath se trouve dans le répertoire utilisateur. Exemples :
   - Windows : `C:\Users\<VotreNom>\QuPath\extensions`
   - macOS : `~/Library/Application Support/QuPath/extensions`
   - Linux : `~/.qupath/extensions`

2. **Copier le fichier .jar :**  
   Déposez le fichier `.jar` téléchargé dans ce dossier.

3. **Redémarrer QuPath :**  
   Fermez puis relancez QuPath pour que l'extension soit détectée et chargée automatiquement.

---

## 4. Utilisation de l'Extension WSI Infer

### 4.1. Chargement d'une Image WSI

1. Lancez QuPath.
2. Ouvrez une image de lame entière (WSI) via `File > Open` ou dans un projet via `Project > Add images...`.

### 4.2. Exécution de l'Extension

1. **Accéder au plugin :**  
   Dans QuPath 0.7, cherchez l'extension dans le menu **Extensions**. Si aucun menu **WSI Infer** n'apparaît après redémarrage, considérez l'extension comme non validée sur votre installation.

2. **Configurer l'inférence :**  
   - Sélectionnez le modèle d'apprentissage profond à utiliser (si plusieurs options sont proposées).
   - Ajustez les paramètres d'exécution (par exemple, seuils de confiance, options de segmentation).

3. **Lancer l'inférence :**  
   Cliquez sur le bouton pour démarrer le processus. L'extension analysera l'image et générera des annotations ou contours de segmentation directement sur l'image.

### 4.3. Visualisation et Exportation des Résultats

1. **Examinez les résultats :**  
   Les annotations générées (par exemple, des contours, des zones colorées) s'affichent en superposition sur l'image WSI.  
   Vous pouvez ajuster la visibilité ou l'opacité des annotations via l'interface.

2. **Exporter les résultats :**  
   Exportez d'abord les annotations ou objets produits, par exemple en GeoJSON ou en table de mesures, selon ce que l'extension ajoute réellement à la hiérarchie QuPath.

En pratique, considérez cette extension comme **à revalider pour QuPath 0.7** tant que le dépôt officiel n'annonce pas explicitement cette compatibilité.
Le bon réflexe est :
1. installer l'extension
2. vérifier qu'elle apparaît dans **Extensions**
3. la tester sur une image simple
4. n'utiliser vos vraies données qu'après validation
